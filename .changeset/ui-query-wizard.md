The query wizard: the tables as in a diagram, each field with a check, the + of a table adding its related ones (a
relation to one as columns of the row, a relation to many as a list through include); a filter on the entity it starts
from with its suggestions, the order and the page, not applied when empty. It writes the query in a new tab, and stays
with it (and with the saved query) to be opened again. The icon of formatting a query is an indent.
