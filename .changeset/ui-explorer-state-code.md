The explorer shows, by the metadata of a schema, its state (its data, the files of data/) and its source code: a node for each language built (node, client-node…), named so, with its files and an action that downloads its folder as a .zip; the source code has the build too (also in the commands of the schema, now `BuildDialog`). The code of each language is written in its own folder of src/ (data-gateway 4.1.0).
