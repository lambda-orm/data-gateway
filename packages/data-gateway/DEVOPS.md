# λORM Base Devops Guide

## Tasks

Main Tasks:

| task   															| Description                                  									  		|
|-------------------------------------|---------------------------------------------------------------------|
| `pnpm run test`											| Run all tests. 															  											|
| `pnpm run release`									| Create a new release. 																							|
| `pnpm run release-manual`						|	Manual release																											|

Subs Tasks:

| task   															| Description                                  									  		|
|:-----------------------------------	|:--------------------------------------------------------------------|
| `pnpm run lint`											| Run the linter. 																										|
| `pnpm run build`										| Build the project. 																									|
| `pnpm run dist`											| Build the project and create a prepare nuw distribution. 						|
| `pnpm run docs`											| Generate the documentation. 																				|
