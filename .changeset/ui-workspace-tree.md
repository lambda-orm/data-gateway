The explorer as the workspace is: each schema with config (the lambdaORM.yaml read first, Edit / Save / Cancel),
domain (entities, enums), application, infrastructure (mappings, sources, stages, the variables of the .env), data and
src → model (their files, read only) and projects (the folders at the top of what is saved). Each element opens in its
own tab, read first with Edit; selecting the schema opens its tab with the commands in a toolbar. `FileView`.
